Instant checks

GitHub runs automatic checks on its own schedule, and they can lag by hours. To make Check now fetch fresh headlines on the spot, give this app a GitHub key that can only start its update. You only do this once per device.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Token name: Musk Wire. Expiration: the longest option offered.
  3. Repository access: Only select repositories, then choose musk-wire.
  4. Permissions: under Repository permissions, click Add permissions, pick Actions, and set it to Read and write.
  5. Click Generate token, copy it, and paste it below.

The key stays on this device only. It can start the update and nothing else: it can't read or change your files or your account.

Instant checks are on for this device.
